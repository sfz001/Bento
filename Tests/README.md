# 回归检查

运行 `./build_app.sh --test`：先对 App 和特权守护进程类型检查，再依次运行回归测试。

- AppDelegate：直接驱动生产会话代码，替代显示控制器，覆盖施加顺序、探测未知、来源隔离、两轮断开、重连取消、演练收尾、真实连接接管、停用及锁定超时。
- 显示恢复：替代 CoreGraphics 镜像接口，覆盖硬件镜像副屏、睡眠重试、失败保留快照、分辨率归属、刷新率和 Dock 等待预算。
- 远程探测：替代进程与日志读取，覆盖认证、伪装路径、PID 复用及不可读信号。
- 布局模型：容错解码、嵌套分割、替换、比例与序列化。
- 手势几何：窗口位移、标签页拖动、上甩/来回甩、极端坐标。
- 图标语义：中英文稳定名称、溢出条四态。
- 日志限速：首次错误、重复计数、恢复、定时汇总与缓存上限。
- 滚动恢复：替代权限查询及 tap 工厂，覆盖已授权却创建失败的分类、首次失败后的定时自愈、授权变化、设置返回后的立即静默重试、唯一 watchdog、stop 停止重试及自动路径不弹权限提示；不创建真实 event tap。
- 权限恢复提示：使用隔离偏好域及替代签名信息，覆盖签名变化、失败启动不覆盖成功授权历史、未知签名的保守提示，以及实际恢复后清除旧提示；不打开真实权限窗口。
- 构建签名：替代 codesign/security，覆盖现有签名的精确复用、缺私钥/撤销/歧义/坏签名拒绝、显式覆盖、新 App 本地默认，以及编译/删包前检查；不访问真实钥匙串。
- 崩溃标记：独立测试子进程触发 SIGTRAP/SIGILL/SIGABRT，检查日志标记和退出信号。
- Claude 防护：首次/重复开启、阻断/恢复/关闭、守护重启幂等、保留其他 hosts、原子替换失败、Clash 核心/TUN/路由/规则校验、旧 Merge 清理及无效调用者拒绝。增加带空格的内核 argv、IPv6 路由未知/旁路、规则优先级、代理组 DIRECT/循环/未知选择链和实际定时器存活回归。全部使用临时文件或替代接口，不修改真实 hosts、Clash 配置或注册守护。
- Clash Script：仅在 JavaScriptCore 中运行测试 fixture，覆盖原 main 与其它字段/规则保留、五条前置、重复安装/调用、JSON 编码、无末尾换行/CRLF 字节恢复、不可包装脚本拒绝、旧 Merge 迁移、文件权限和链接/FIFO 拒绝。生产 root daemon 不执行 JavaScript。
- Claude XPC 授权：真实匿名 NSXPC 连接覆盖匹配签名要求放行、不同 ID/证书拒绝、缺失或无效 requirement 拒绝，并复现 audit token 的 NSValue 装箱及 SecCode 各阶段返回码。需要允许系统 CodeSigningHelper/XPC；受限执行沙箱中的连接错误不代表签名测试结果，应在沙箱外运行。

测试不施加真实 gamma、不改显示布局或 Dock、不启动屏保，也不申请辅助功能权限。测试临时文件自动清理；崩溃子进程可能产生系统诊断报告。

真实硬件演练由用户在 Bento 菜单中选择「熄屏流程演练…」并确认后启动：10 秒后通过同一套锁定确认和恢复流程收尾；真实远程连接会取消演练计时并接管会话。演练需要远程监控已开启且当前无会话。
