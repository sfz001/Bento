# 回归检查

运行 `./build_app.sh --test`：先类型检查，再依次运行 8 组测试。

- AppDelegate：直接驱动生产会话代码，替代显示控制器，覆盖施加顺序、探测未知、来源隔离、两轮断开、重连取消、演练收尾、真实连接接管、停用及锁定超时。
- 显示恢复：替代 CoreGraphics 镜像接口，覆盖硬件镜像副屏、睡眠重试、失败保留快照、分辨率归属、刷新率和 Dock 等待预算。
- 远程探测：替代进程与日志读取，覆盖认证、伪装路径、PID 复用及不可读信号。
- 布局模型：容错解码、嵌套分割、替换、比例与序列化。
- 手势几何：窗口位移、标签页拖动、上甩/来回甩、极端坐标。
- 图标语义：中英文稳定名称、溢出条四态。
- 日志限速：首次错误、重复计数、恢复、定时汇总与缓存上限。
- 崩溃标记：独立测试子进程触发 SIGTRAP/SIGILL/SIGABRT，检查日志标记和退出信号。

测试不施加真实 gamma、不改显示布局或 Dock、不启动屏保，也不申请辅助功能权限。测试临时文件自动清理；崩溃子进程可能产生系统诊断报告。

真实硬件演练由用户在 Bento 菜单中选择「熄屏流程演练…」并确认后启动：10 秒后通过同一套锁定确认和恢复流程收尾；真实远程连接会取消演练计时并接管会话。演练需要远程监控已开启且当前无会话。
